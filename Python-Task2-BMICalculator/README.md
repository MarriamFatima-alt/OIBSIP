# BMI Calculator - Task 2

## Objective
A Python program that calculates a user's Body Mass Index (BMI) 
based on their weight and height, and classifies the result into 
standard health categories.

## Tech Stack
- Python 3
- Built-in libraries only (no external dependencies)

## Features
- Takes weight (kg) and height (m) as input
- Calculates BMI using the formula: BMI = weight / (height²)
- Classifies BMI into: Underweight, Normal, Overweight, Obese
- Input validation: rejects non-numeric and negative values
- Displays BMI rounded to 2 decimal places
